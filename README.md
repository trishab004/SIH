*🌐 Multilingual Login System*
🏆 SIH 2025 Project | Empowering Inclusivity through Language
📝 Project Description
In a land of many languages, a single interface often leaves many behind.
This project presents a Multilingual Login System, designed for public service portals, transportation apps, and employee–passenger interaction platforms, ensuring no user feels alienated due to language barriers.

This system allows users to choose between English, Hindi, and Bengali, offering a smooth and accessible login/signup experience in their native language.

✨ "Technology should speak the user's language — not the other way around."

🎯 Problem Statement
In a culturally diverse country like India, where over 22 official languages bloom across states, most digital interfaces are English-centric, excluding a large demographic from effectively using essential services. This leads to:

User confusion and dropouts

Security risks due to misinterpretation

Inequitable access to public digital infrastructure

The challenge was to design an intuitive multilingual login interface, accessible to both employees and passengers, minimizing linguistic friction.

🛠️ Features
🌍 Language Selection Interface
Supports English, Hindi, and Bengali — scalable to more.

🔐 Dual Login Paths
For employees (ID-based) and passengers (phone number-based).

📝 Multilingual Sign Up
Intelligently translated placeholders, buttons, alerts, and titles.

💡 Dynamic Content Translation
Using JavaScript-based language mapping.

💬 Localized Feedback
Login and signup messages appear in the user's selected language.

📦 Lightweight & Responsive
Built with vanilla HTML, CSS, and JS — no backend dependency (yet!).

🧩 Technologies Used
🧱 HTML5 & CSS3 – Frontend design and layout

🧠 JavaScript – Logic for multilingual handling and UI updates

💾 LocalStorage – To store user’s language preference

📱 Responsive Design – Ensures accessibility across devices

🚀 How to Run
Download or clone this repository

Open index.html in your browser

Select your preferred language

Login or sign up as Employee or Passenger

Watch the interface adapt to your chosen tongue!
